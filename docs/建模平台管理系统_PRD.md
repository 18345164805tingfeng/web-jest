# 建模平台管理系统 PRD

## 1. 项目概述

建模平台管理系统面向企业 AI/算法平台团队，提供模型资产、训练任务、推理服务、数据集、监控指标和平台治理的一体化管理入口。本次版本根据 Figma Site 新设计稿实现，视觉定位为深色科技风 MODELHUB 控制台。

## 2. 产品目标

- 建立统一的模型生命周期管理入口。
- 帮助平台管理员实时掌握模型、训练、推理和算力状态。
- 支持算法工程师快速检索模型、查看训练进度和定位异常。
- 提供监控指标与告警能力，支撑线上稳定性治理。

## 3. 用户角色

- 平台管理员：关注系统总览、告警、GPU 资源、访问控制和系统设置。
- 算法工程师：关注模型管理、训练任务、数据集和模型评估。
- 业务负责人：关注模型调用量、SLA、错误率和部署状态。
- 运维人员：关注推理服务、延迟分布、错误趋势和资源水位。

## 4. 信息架构

系统左侧导航包含：

- 总览
- 模型管理
- 训练任务
- 数据集
- 推理服务
- 监控指标
- 访问控制
- 系统设置

顶部栏包含：

- 面包屑：MODELHUB / 当前模块
- 快速搜索
- 系统设置入口
- 通知入口

## 5. 核心功能

### 5.1 系统总览

展示在线模型、运行任务、今日推理、数据集容量等核心指标。提供 QPS 与延迟趋势、GPU 利用率、近期训练任务和系统告警列表。

### 5.2 模型管理

支持按模型名称、模型家族搜索，按任务类型筛选。列表展示模型名称、版本、任务、框架、参数量、大小、准确率、调用量、部署状态和更新时间。支持收藏模型、查看和部署入口。

### 5.3 训练任务

展示训练任务 ID、模型、类型、进度、ETA、状态和操作。任务可展开查看 Epoch、Step、学习率、Loss、GPU 数量、显存、数据集、Batch Size 和 Loss 曲线。支持查看训练日志。

### 5.4 监控指标

展示 P50/P95/P99 延迟、错误率和整体 SLA。提供 24 小时延迟分布、近 14 日错误率趋势、模型性能对比和模型 SLA 状态。

### 5.5 待扩展模块

数据集、推理服务、访问控制、系统设置在当前版本提供导航与占位页面，后续可独立迭代。

## 6. 关键交互

- 侧边栏点击切换业务模块。
- 模型管理支持实时搜索和分类筛选。
- 模型支持收藏状态切换。
- 训练任务支持展开/收起详情。
- 训练任务支持显示/隐藏日志面板。
- 监控指标支持时间范围筛选控件展示。

## 8. 非功能需求

- 响应式支持桌面和窄屏查看。
- 保持深色主题一致性，强调低亮度背景与青色主色。
- 关键列表与图表区域应支持横向溢出处理。
- Mock 数据应集中在 `src/data`，便于后续替换 API。
- 组件按通用组件、布局组件、业务页面分层，降低维护成本。

## 9. 当前交付范围

- Vue3 + Vite 项目工程。
- 符合设计稿风格的深色控制台 UI。
- 总览、模型管理、训练任务、监控指标页面。
- 数据集、推理服务、访问控制、系统设置占位。
- PRD 文档与源码压缩包。
